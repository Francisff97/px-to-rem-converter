# PX → REM Converter — Chrome extension

A tiny Chrome extension that converts **px to rem** while you write HTML, CSS or JavaScript, so you don't have to do the math by hand.

## Features

- Instant px → rem conversion (16px base) from the browser toolbar popup
- Works offline: it's a plain HTML/CSS/JS extension
- Can also run locally by opening `index.html`

## Install (unpacked)

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the project folder.

Google's guide: https://support.google.com/chrome/a/answer/2714278

## Tech stack

Manifest V3 · vanilla JavaScript · HTML · CSS
